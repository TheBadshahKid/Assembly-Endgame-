
# ⚔️ Assembly: Endgame

**A visually rich, high-stakes word guessing game where programming languages face extinction!**

> Save the programming world one letter at a time... or watch it fall to Assembly.

## 🚀 Features

- 🧠 **Word Guessing** – Classic hangman-style gameplay with a developer twist.
- 🔥 **Streak System** – Rack up consecutive wins for rare achievements.
- 💡 **Power-Ups** – Use hints, reveal letters, and strategic freeze moves.
- 💀 **Roasts** – Lose a game and get hilariously roasted.
- 🎉 **Achievements** – Unlock hidden badges based on your performance.
- 🎨 **Themes** – Switch between **Dark**, **Cyberpunk**, and **Matrix** modes.
- 💥 **Particle Effects** – Juicy feedback with emoji bursts and screen shake.
- 🎵 **Custom Audio** – Pure JavaScript sound generation using Web Audio API.
- 📊 **Local Stats** – Win/loss tracking, perfect games, and fastest wins.
- 📤 **Share** – Tweet your roast-worthy defeat directly.

---

## 🧠 Gameplay

- Guess the hidden word letter by letter.
- Each wrong guess eliminates a programming language.
- Win by saving the word. Lose and Assembly takes over!
- Play again with new words and challenges.

---

## 🏆 Achievement System

Achievements include:

- `🥇 First Win` – Win your first match.
- `🔥 Streak Master` – Win 3+ games in a row.
- `💎 Perfect Game` – Win without a single mistake.
- `⚡ Speedrun` – Win in under 30 seconds.
- ...and more!

Progress is saved in your browser's localStorage.
